1. Vision & Product Requirements
Create a recruiter-focused portfolio that immediately communicates expertise, highlights flagship projects, and demonstrates engineering quality through thoughtful UI, motion, accessibility and performance.
2. Motion Design System
Adopt subtle, purposeful animations using transform and opacity. Include a loading screen, staggered hero animations, scroll reveals, interactive cards, animated navigation, floating background elements and reduced-motion support.
3. Website Architecture
Include Hero, About, Skills, Featured Projects, Timeline, GitHub Showcase, Contact and Footer. Highlight ChronoAI and Expense Tracker as primary projects. Use reusable layouts and consistent spacing.
4. Premium UI/UX Design System
Use a dark theme with glassmorphism, an 8-point spacing system, responsive typography, consistent colours, reusable buttons, accessible forms, and a cohesive visual language.
5. React Architecture & Project Structure
Build with React + Vite using reusable components, data-driven rendering, modular CSS, custom hooks, lazy loading and scalable folder organisation.
6. Premium Component Library
Define reusable Navbar, Hero, Buttons, Cards, Timeline, Contact Form, Footer, Loading Screen and Cursor components. Centralise colours, spacing, typography and animation tokens.
7. Animation Implementation Guide
Implement performant CSS and JavaScript animations with IntersectionObserver, requestAnimationFrame where appropriate, GPU-friendly transforms, accessible interactions and cross-browser testing.
8. Responsive Design System
Design mobile-first with fluid layouts, 12/8/4-column grids, touch-friendly controls, responsive media, adaptive navigation and comprehensive device testing.
9. Performance, Accessibility, SEO & Production Readiness
Target Lighthouse scores above 95. Optimise Core Web Vitals, implement WCAG-oriented accessibility, semantic HTML, metadata, structured data, security best practices and production deployment.
