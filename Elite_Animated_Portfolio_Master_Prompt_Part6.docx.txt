Elite Animated Portfolio Specification - Part 6
Premium Component Library
Navbar
Sticky glass navigation with logo, section links, active underline, shrink-on-scroll behaviour, mobile hamburger menu, smooth scroll, keyboard navigation and visible focus states.
Hero
Reusable hero component containing greeting, animated name, role switcher, short value proposition, CTA buttons, profile image, floating technology icons and background effects.
Section Container
Standard wrapper providing max-width, responsive padding, consistent spacing and section title styling.
Buttons
Primary, secondary and icon buttons. Define hover, focus, active, disabled and loading states. Ripple effect implemented with CSS/JavaScript only.
Project Card
Large reusable card with image, title, description, technology badges, GitHub button, Live Demo button, hover elevation, gradient border and subtle 3D tilt.
Skill Card
Glass card with technology icon, title, optional proficiency indicator, hover glow and icon animation.
Timeline Item
Alternating timeline cards with connector line, reveal animation and responsive stacked layout on mobile.
Social Icons
Consistent circular icons with hover lift, colour transition and accessible labels.
Contact Form
Reusable input, textarea and submit components. Client-side validation, loading state, success state and accessible error messages.
Footer
Minimal footer containing copyright, quick navigation, social links and animated back-to-top button.
Loading Screen
Brand-inspired loading overlay with animated logo, progress indicator and smooth fade-out before initial render.
Cursor & Background
Optional custom cursor follower, mouse spotlight and animated grid background. Disable automatically on touch devices.
Reusable Design Tokens
Create shared variables for:• Colours• Typography• Border radius• Shadows• Animation durations• Easing curves• Z-index layers• Spacing scale• BreakpointsEvery component must consume these shared tokens instead of hard-coded values.
Interaction Standards
Every interactive element must provide:✓ Hover feedback✓ Keyboard focus indication✓ Active state✓ Smooth transition✓ Accessible contrast✓ Touch-friendly hit area (minimum 44px).
Acceptance Criteria
All components must look and behave as parts of one coherent design system. New sections should be buildable by composing existing components without rewriting styles or interactions.
