Elite Animated Portfolio Specification - Part 2
Motion Design System
MISSIONCreate a motion system that feels premium, intentional and performant. Motion must reinforce hierarchy and guide the user's attention. Never animate purely for decoration.ANIMATION PRINCIPLES• Target 60 FPS.• Use only CSS animations/transitions, requestAnimationFrame and IntersectionObserver.• Animate transform and opacity whenever possible.• Avoid animating layout properties.• Duration ranges:  - Micro interactions: 150–250 ms  - Hover: 200–300 ms  - Section reveals: 500–700 ms  - Hero entrance: 900–1200 ms• Use ease-out for entrances and ease-in-out for interactions.• Stagger related elements by 60–120 ms.GLOBAL MOTION1. Custom loading screen with animated logo and progress indicator.2. Hero text revealed letter-by-letter.3. Floating technology icons with slow drift.4. Glass cards elevate with subtle scale and shadow.5. Sticky navigation shrinks on scroll.6. Active navigation underline animates smoothly.7. Scroll progress indicator at top of page.8. Custom cursor follower with magnetic button interaction.9. Background grid shifts subtly with mouse movement.10. Mouse spotlight effect over cards.SECTION ANIMATIONSHero:- Fade + slide headline.- CTA buttons rise independently.- Profile image enters with masked reveal.- Floating blobs move slowly.About:- Timeline reveals on scroll.- Statistics count upward.- Image tilts slightly with pointer movement.Skills:- Cards reveal in staggered grid.- Icons rotate 5–8 degrees on hover.- Progress indicators animate from 0%.Projects:- Each card fades and rises independently.- 3D tilt based on pointer position.- Animated gradient border on hover.- Screenshot zoom effect.- GitHub and Live Demo buttons use ripple effect.Contact:- Inputs animate into focus.- Icons pulse gently.- Submit button includes loading state.PERFORMANCE REQUIREMENTS• Pause off-screen animations.• Respect prefers-reduced-motion.• No animation should block interaction.• No dropped frames on modern browsers.COMPLETION CRITERIAMotion should make the portfolio feel like a polished software product rather than a slideshow. Recruiters should perceive responsiveness, craftsmanship and attention to detail from the interactions alone.
