Elite Animated Portfolio Specification - Part 4
Premium UI/UX Design System
1. Design Philosophy
Every component must appear handcrafted. Prioritise clarity, hierarchy and consistency over visual effects. Use motion only to reinforce usability.
2. Colour System
Primary Background: #050816Surface: rgba(255,255,255,0.06)Surface Hover: rgba(255,255,255,0.10)Primary Accent: #4F8CFFSecondary Accent: #00E0FFPrimary Text: #FFFFFFSecondary Text: #B7C3D7Border: rgba(255,255,255,0.12)Success: #22C55EWarning: #F59E0BError: #EF4444
3. Typography
Headings: Modern geometric sans-serif.H1: 64px desktop / 42px mobile.H2: 42px / 32px.H3: 28px / 24px.Body: 18px / 16px.Line-height: 1.6.Use bold only for emphasis and maintain generous whitespace.
4. Spacing System
Adopt an 8-point spacing scale (8,16,24,32,48,64,96,128px). Maintain consistent margins and padding across all sections.
5. Grid System
12-column desktop grid, 8-column tablet, 4-column mobile. Maximum content width around 1200px with centred layout.
6. Glassmorphism
Cards should use translucent backgrounds, 16–24px blur, subtle borders, soft shadows and restrained glow. Avoid heavy opacity or excessive blur.
7. Buttons
Primary button: filled accent with hover lift. Secondary: glass outline. Include hover, focus, active and disabled states. Corners 12–16px.
8. Cards
Project and skill cards share consistent radius, padding and elevation. Hover should slightly raise the card, increase shadow and animate border.
9. Forms
Rounded accessible inputs, visible focus states, floating labels optional, inline validation messages, keyboard friendly.
10. Icons
Use one icon style throughout. Icons should complement headings and animate subtly on hover without spinning.
11. Responsive Rules
Every section must gracefully reflow. Never hide important content on mobile. Optimise touch targets to at least 44px.
12. Visual Consistency Checklist
Consistent spacing, consistent shadows, consistent animation timing, reusable design tokens, no random colours, no inconsistent border radii, no overlapping elements.
Acceptance Criteria
The portfolio should resemble a premium SaaS product rather than a student template. Every component must feel intentional, cohesive and production-ready while remaining fast, accessible and recruiter-focused.
